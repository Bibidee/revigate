# Start here

Revigate now operates as a non-custodial rulebook Registry.

1. Read [the implementation status](docs/IMPLEMENTATION_STATUS.md).
2. Configure `NEXT_PUBLIC_REVIGATE_REGISTRY` only after deploying and source-checking Registry v2.
3. Run `npm run preflight` before publishing.
4. Treat the older escrow and Vault documents as historical security evidence only.

No user should send funds to any past Revigate contract address.
