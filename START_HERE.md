# Start here

Revigate now has one active contract: `contracts/revigate.py`.

1. Read [the implementation status](docs/IMPLEMENTATION_STATUS.md).
2. Set `NEXT_PUBLIC_REVIGATE_CONTRACT` only to a source-attested Studionet deployment of that exact file.
3. Run `npm run preflight` before publishing.
4. Keep production writes and custody disabled until the live failure and recipient-delivery gates in the implementation status are closed.

The old Registry/Vault candidates and their deployment evidence are archived; they are not part of the active product.
